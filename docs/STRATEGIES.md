# Strategy reference (as built)

All five strategies evaluate closed-bar `MarketSnapshot` inputs. Missing data, insufficient history, invalid computed values, or failed confirmation returns no candidate. Common candidate finalization filters in `app/strategies/base.py` also apply. Class E/F values are configuration assumptions, not empirically calibrated thresholds.

| Strategy | Purpose | Required inputs and fail-closed conditions |
|---|---|---|
| **S1 — Liquidity Sweep & Reclaim** | Sweep/reclaim of a recent 5m high/low with directional taker-flow confirmation. | Needs the shared minimum closed 5m bars, positive Wilder ATR, a complete configured swing lookback, and non-stale `taker_flow` with nonzero volume so a buy ratio can be computed. Missing/stale flow returns no candidate. S1 itself does not require derivative history. |
| **S2 — Volatility Compression → Range Expansion** | Compression followed by range break, volume expansion, and OI change. | Needs 5m bars of `max(min_candles, range_bars + atr_percentile_window + atr_period + 1)`, at least two 15m bars, valid ATR/volume statistics, and derivative state with at least two 5m OI points. Latest 5m OI must be fresh; prior OI cannot be zero; configured OI-change confirmation is mandatory. Missing/stale OI returns no candidate; there is no price-only fallback. |
| **S3 — Funding / Crowding Exhaustion Reversal** | Extreme funding/crowding plus reversal in price structure and taker flow. | Needs shared minimum 5m history and 10 15m bars; derivative state; configured funding z-score window with fresh latest funding; at least two fresh 5m OI points; a fresh non-empty global account long/short ratio series; and configured 1d OI points for percentile ranking. It also requires parseable taker buy ratio, a structure break opposite the crowded side, and a taker-flow flip in that direction. S3 itself does not check taker-flow freshness; live feed-health/veto checks are separate. Funding alone cannot trigger S3. |
| **S4 — OI-Confirmed Trend Continuation** | Trend continuation with higher-timeframe alignment, structure, pullback, and OI expansion. | Needs shared minimum 5m bars; enough 1h data for slow EMA plus slope lookback; enough 4h data for slow EMA; configured 15m structure history; valid ATR/EMA series; and non-empty fresh 5m OI history long enough for its window and corresponding price comparison. It requires aligned 4h trend, HH/HL or LH/LL 15m structure, a 5m pullback, price movement, and OI expansion. Missing/stale OI or incomplete required timeframe fails closed. S4 does not consume taker-flow ratio. |
| **S5 — OI Regime Shift** | OI regime transition aligned with price/taker direction; funding is veto-only. | Needs shared minimum 5m bars, derivative state, at least 13 5m OI points (and enough for the configured regime-shift window), fresh latest OI, and configured 1d OI percentile history. Zero reference OI, noise-band move, no percentile crossing, ambiguous/weak price-OI quadrant, missing/invalid taker flow, or misaligned taker flow returns no candidate. Funding is optional and only vetoes when enough values are present to calculate an opposing z-score; the strategy does not require funding history to produce a candidate. It does not consume long/short ratio history. Its TP2 R:R check also runs before consensus. |

## Data cadence and caveats

Live OI is polled separately from historical OI. Historical refresh maintains the four OI periods and funding/global-account/taker series used by strategies; API results merge by event timestamp, retaining older percentile history. Refresh failures preserve the previous cache for the affected endpoint and are logged.

A strategy candidate is not approval by consensus, veto, risk, sizing, persistence, or delivery. Deterministic tests use synthetic fixtures; strategy values have not been validated against representative live or out-of-sample data. No thresholds were tuned in this documentation update.
